# Release v2026.11.1

Released 2026-10-31. Upgrades from: `v2026.11.0`.

Upgrade one release at a time:

```bash
git fetch upstream --tags
git merge v2026.11.1
./platformctl upgrade <env>
```

## Kubernetes

Supported: 1.36. Recommended: 1.36.

## Before you upgrade

Nothing to do beyond `./platformctl upgrade`.

## Changes

- `./platformctl up` refuses an env name that would make the EKS system node
  group name prefix longer than 37 characters (at most 9 characters with the
  default `resources_prefix`), before anything is created.
- `./platformctl down` waits for Argo CD to finish deleting its applications
  before draining Karpenter's nodes, so teardown no longer waits out the drain
  timeout on pods of apps that are still being deleted.
- The Cognito seed users are created without an invitation email. Each invite
  used Cognito's small default daily email quota for the account and region;
  once it ran out, `up` failed after over an hour of retries.
