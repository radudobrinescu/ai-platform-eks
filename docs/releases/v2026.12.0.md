# Release v2026.12.0

Released 2026-11-19. Upgrades from: `baseline`.

To upgrade an environment:

```bash
./platformctl upgrade <env>
```

Releases are applied one at a time, in order. See UPGRADING.md.

## Kubernetes

Supported: 1.36, 1.37. Recommended: 1.37.

## Before you upgrade

Manual steps:
- Langfuse moves to chart 2 (Langfuse 4) and starts with empty trace storage: traces, observations, scores and sessions recorded before this release are not carried over. Export any you need from the Langfuse UI before upgrading. Projects, users, API keys, prompts and datasets (kept in Postgres) stay.
- Teams onboarded with --langfuse-secret: their per-team LiteLLM callback is the old 'langfuse' callback, which Langfuse 4 rejects. After the upgrade, add it again as 'langfuse_otel' (LiteLLM POST /team/<team_id>/callback, as in platform/config/kro/team-onboarding.yaml) and remove the old one. Platform-wide tracing needs nothing.

## Platform changes

Fixes:

- Remove nodes the release no longer allows that never became ready
- An upgrade keeps the model cache bucket
- Clear Argo CD hook finalizers so namespaces finish deleting
- Pin Argo CD's Redis to a patched image by digest
- Teardown waits stop as soon as nothing is progressing
- Kubectl provider explicit in the OSS observability stage; kro CRDs follow the chart
- Clear KEDA finalizers so an llm-d model cannot hold its namespace
- Apply Karpenter and LB Controller CRDs from their pinned charts
- Clear leaked ENIs before security groups; fail if destroy never completes
- Create seed users without an invitation email
- Refuse env names EKS cannot hold; wait for Argo CD before the node drain
- Write the seed users' role attribute without the custom: prefix
- Exclude g7/g7e GPU nodes; force a Karpenter drain that cannot finish
- Let Karpenter remove its own nodes before Terraform runs
- Keep the teardown watchdog alive through errors
- Refresh the models ApplicationSet; restart LiteLLM after the last model
- Keep a live cluster's KMS key; clear pods stranded on dead nodes
- Read aws_oss_tooling_config keys with lookup()
- Teardown hardening (failed up, Karpenter orphans, leftover SGs)
- Readiness, Bedrock drift and delete, price scale
- Pin the self-managed Argo CD chart to 10.10.5

Improvements:

- One command upgrades through every release in order
- Chart 2 (Langfuse 4) with our own ClickHouse; drop Langfuse 1.x data
- Guarded 'upgrade' command, release manifests, UPGRADING.md

Other changes:

- Remove leftover files and correct stale documentation
- Say what the image digests are for; guard the published tree
- Pin kustomize to the v5.8.3 release tarball
